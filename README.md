# CG_toolkit
An interactive computer graphics learning toolkit built in plain HTML, CSS and JavaScript for our third semester subject course project. Step-by-step visualizers for DDA, Bresenham, midpoint circle and area fill, plus 2D and 3D transformation labs. Every pixel is rasterized by hand(using actual algorithms), with no canvas drawing shortcuts.
